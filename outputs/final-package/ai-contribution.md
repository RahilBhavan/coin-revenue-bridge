# AI contribution record

## Disclosure

This portfolio project was developed with substantial AI assistance. AI was used as an implementation and review tool; the public filings and generated artifacts—not the model’s prose—are the evidence base. A reviewer should evaluate the workbook, source register, code, and validation outputs directly.

## What AI contributed

- structured the project brief, decision gates, design alternatives, and scope cuts;
- helped inspect and normalize the already-downloaded SEC-hosted shareholder-letter evidence;
- wrote Python, SQL, and JavaScript used for the analytical core and workbook generation;
- generated the descriptive bridge, memo, reviewer packet, interactive demo, and captioned WebM video;
- wrote and ran automated tests for cutoff control, definition compatibility, missing/zero volume, metric formulas, reconciliation, and forecast refusal on descriptive-only data;
- performed an adversarial review and surfaced the small-sample, definition-vintage, effective-yield, and bridge-order limitations;
- produced this contribution record and the machine-readable validation evidence.

## What AI did not establish

- It did not create access to Coinbase internal data, confirm management intent, or validate causal drivers.
- It did not establish an investment view, a production forecast, or model superiority.
- It did not verify current openings or hiring outcomes.
- It did not bypass the earlier browser admin-policy restriction on Coinbase careers navigation.
- It did not deploy, publish, transact, create accounts, contact anyone, or install project dependencies.

## Human responsibility before external use

A human owner should independently spot-check the featured source-table values against the frozen SEC exhibits, review the workbook formulas, decide whether the public-data scope is suitable for the intended audience, and approve every external claim. Any extension into Q4 2025 or later requires a new definition-vintage reconciliation because Coinbase changed the Trading Volume definition.

## Reproducibility boundary

The analytical logic and demo are deterministic from the checked-in local inputs. The workbook validator passed in the provided workspace, and the workbook was rebuilt successfully in an isolated clean workspace using the declared bundled runtime. This is stronger than an in-place rerun, but it is not proof of portability to every operating system or arbitrary dependency version. See `validation-report.md` for the exact checks and `validation-evidence.json` for hashes and computed evidence.
